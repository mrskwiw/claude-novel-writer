# Context Engine Spec

## Purpose
Assemble optimal context for AI operations without exceeding limits.

## Inputs
- Current scene/chapter
- Relevant characters
- Active plot threads
- World rules
- Recent text

## Outputs
- Ranked, compressed context blocks
- Deterministic + agentic hybrid pipeline

## Components
- Context Assembler
- Relevance Ranker (semantic similarity)
- Compression Layer (optional/skippable per your direction)
- Rules Engine

## Future Direction
- Semantic retrieval over keyword
- Deterministic recall guarantees
