# Core Architecture

## Principles
- Hybrid File + Database (Markdown/YAML as source of truth, SQLite for queries)
- Builder Pattern for all entities
- Bidirectional Sync
- MCP-first database access
- Context assembly for AI

## Core Systems
- CLI Interface
- Command Handlers
- Builder Layer
- Sync Managers
- Database Layer
- Context Engine (future-critical)

## Key Entities
- Chapters, Scenes
- Characters
- Locations
- Plot Threads
- World Rules
