**Overall target:** [e.g., "1-2 per page" or "5-7 per 1000 words"]

**Preferred adverb types:**
- **Manner (-ly adverbs):** [e.g., "Use sparingly. Only when verb alone is insufficient."]
- **Time/Frequency:** [e.g., "More acceptable. 'Always', 'never', 'often'."]
- **Degree/Intensity:** [e.g., "Use with caution. 'Very', 'extremely', 'quite'."]

**Specific rules:**
- [e.g., "Never use 'very' with a strong verb"]
- [e.g., "Prefer 'sprinted' over 'ran quickly'"]
- [e.g., "In dialogue tags: only when essential to meaning"]

**Examples of acceptable use:**
```
✓ "He always arrived late." (frequency)
✓ "She smiled genuinely." (manner, when 'smiled' alone is ambiguous)
✗ "He ran quickly." (use 'sprinted' instead)
✗ "She was very tired." (use 'exhausted' instead)
```

## Punctuation Style

### Em Dashes
**Frequency:** [e.g., "3-5 per chapter"]
**Usage:** [e.g., "For interruptions, sudden shifts, or parenthetical emphasis"]

**Examples:**
```
"The truth—the real truth—was much worse."
"She was about to speak when—"
```

### Semicolons
**Frequency:** [e.g., "0-2 per chapter" or "Avoid except in lists"]
**Usage:** [e.g., "Only for closely related independent clauses"]

### Ellipses
**Frequency:** [e.g., "Sparingly—primarily in dialogue"]
**Usage:** [e.g., "For trailing off, hesitation, not as substitute for em dash"]

**Examples:**
```
"I thought maybe we could... never mind."
"She's... gone?"
```

### Dialogue Punctuation
**Tag placement:** [e.g., "Prefer tags at end or middle, not opening"]
**Comma vs period:** [e.g., "Comma before closing quote when tag follows"]
**Action beats:** [e.g., "Prefer action beats over tags when possible"]

**Examples:**
```
✓ "I can't do this," she said.
✓ "I can't do this." She turned away.
✓ "I can't," she said, "do this."
✗ She said, "I can't do this."
```

## Usage Guidelines for AI Editors

**Developmental Editor:**
- Check sentence length variation matches target ranges
- Flag sections where pacing doesn't match scene type
- Identify rhythm problems (too many long/short sentences in a row)

**Copy Editor:**
- Count adverb/adjective density per page
- Flag modifier stacking violations
- Check punctuation consistency with these rules

**Line Editor:**
- Suggest stronger verbs to replace adverb + weak verb
- Recommend specific adjectives over generic ones
- Identify filter words in deep POV sections

**Content Generator:**
- Match sentence structure patterns when generating new content
- Respect modifier density targets
- Follow punctuation style preferences
